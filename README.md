# D2K — Dynamic2Keenetic

D2K работает на роутере и снимает блокировки сайтов.

D2K смотрит трафик. D2K измеряет соединение, которое не работает. D2K
подбирает обход и запоминает его.

D2K не использует список заблокированных сайтов. D2K находит каждый обход
сам.

> Проект предназначен для исследования сетевых протоколов и изучения работы
> систем анализа трафика. Используйте его только в учебных целях.

## Что умеет D2K

D2K работает с этими протоколами:

- TLS 1.2 и TLS 1.3;
- QUIC (HTTP/3);
- открытый HTTP;
- голос Discord;
- IPv4 и IPv6.

Весь код D2K написан на C. D2K не использует Zapret и nfqws.

## Установка на Keenetic

Шаги 1–4 делаются один раз. Если Entware уже стоит, начните с шага 4.

### 1) Компоненты KeeneticOS

Откройте веб-интерфейс роутера (обычно **http://192.168.1.1**). Перейдите в
«Общие настройки» → «Изменить набор компонентов». Включите:

1. **«Модули ядра подсистемы Netfilter»** — обязательно, на любой прошивке.
   Без них D2K не запустится.
2. **«Поддержка открытых пакетов»** (OPKG) — нужна для Entware.
3. **«Протокол IPv6»** — только на старых прошивках. На новых прошивках
   IPv6 уже включён, и этого пункта в списке нет.

На части прошивок пункт «Модули ядра подсистемы Netfilter» появляется только
после выбора «Протокол IPv6».

Нажмите «Установить обновление». Роутер перезагрузится.

### 2) USB-накопитель и Entware

Entware ставится на USB-накопитель. Сделайте всё по официальной инструкции
Keenetic: https://help.keenetic.com/hc/ru/articles/360021214160

Инструкция написана для одной модели. Шаги одинаковы для всех моделей с
USB-портом.

Если Entware не устанавливается (сервер пакетов `bin.entware.net` обрывает
загрузку), возьмите офлайн-установщик из репозитория
[entware-offline](https://github.com/necronicle/entware-offline): официальный
установщик с пакетами внутри, сеть при установке не нужна.

### 3) Вход по SSH в Entware

С компьютера в той же сети:

```sh
ssh root@192.168.1.1 -p 222
```

Пароль Entware по умолчанию — `keenetic`. Смените его командой `passwd`.

**ВНИМАНИЕ:** Порт 222 — это Entware. Командная строка самого KeeneticOS
(порт 22 или telnet) для D2K не подходит.

На Windows используйте PuTTY или «Терминал» Windows 10/11 (команда `ssh` в
нём есть).

### 4) Пакеты Entware

```sh
p=http://85.192.60.175:9444; pk="curl ca-bundle iptables ipset kmod_ndms xtables-addons_legacy openssl-util"
{ http_proxy=$p opkg update && http_proxy=$p opkg install $pk; } || { opkg update && opkg install $pk; }
```

Команда сначала скачивает пакеты через VPS проекта, а если он не отвечает —
напрямую с сервера Entware.

### 5) Остановите z2k и Zapret

**ВНИМАНИЕ:** Не запускайте D2K вместе с z2k или Zapret. Две программы на
одном трафике мешают друг другу.

Если стоит z2k:

```sh
/opt/etc/init.d/S99zapret2 stop
```

Чтобы z2k не запускался после перезагрузки, удалите его (раздел «Удаление» в
README z2k) или переименуйте файл `/opt/etc/init.d/S99zapret2`.

### 6) Установка D2K

Выполните в том же SSH-терминале Entware:

```sh
(f=$(mktemp); u=https://raw.githubusercontent.com/necronicle/d2k/main/scripts/install.sh; { curl -fsSL --proxy http://85.192.60.175:9444 --connect-timeout 8 --max-time 120 "$u" -o "$f" || curl -fsSL --connect-timeout 10 --max-time 120 "$u" -o "$f"; } && D2K_REF=main sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

В конце установщик печатает адрес панели. Дальше — раздел
[Проверка после установки](#проверка-после-установки).

Выполните команду один раз. Потом D2K обновляет себя сам.

## Установка на OpenWrt

Нужно:

- OpenWrt 22.03 или новее;
- SSH-доступ от root;
- 21 МиБ свободного места в разделе с `/opt` и 17,2 МиБ в `/tmp`.

Entware на OpenWrt не нужен.

`/tmp` на OpenWrt находится в оперативной памяти. **Роутеру с 8 или 16 МиБ
флеша места не хватит:** подключите USB-накопитель и разместите `/opt` на нём.

### 1) Вход по SSH

```sh
ssh root@192.168.1.1
```

Проверьте место: `df -h /opt /tmp`.

### 2) curl

В OpenWrt 25.12 команда использует `apk`, в 24.10 и старше — `opkg`:

```sh
p=http://85.192.60.175:9444; f=/tmp/d2k-feeds
if [ -x /usr/bin/apk ]; then
  cat /etc/apk/repositories.d/*.list | sed -n 's|^https://downloads.openwrt.org/|http://downloads.openwrt.org/|p' > $f
  { http_proxy=$p apk --repositories-file $f update && http_proxy=$p apk --repositories-file $f add curl ca-bundle; } || { apk update && apk add curl ca-bundle; }
else
  { grep -v '^src' /etc/opkg.conf; sed -n 's|^\(src/gz [^ ]*\) https://downloads.openwrt.org/|\1 http://downloads.openwrt.org/|p' /etc/opkg/*.conf; } > $f
  { http_proxy=$p opkg -f $f update && http_proxy=$p opkg -f $f install curl ca-bundle; } 2>/dev/null || { opkg update && opkg install curl ca-bundle; }
fi; rm -f $f
```

Остальные пакеты ставит установщик — тоже сначала через VPS проекта.

### 3) Установка D2K

Та же команда, что для Keenetic (шаг 6 выше). Выполните её в SSH-терминале
роутера.

## Если не скачивается

Каждая команда выше сама пробует два пути: сначала VPS проекта, потом
напрямую. Если не прошли оба, проверьте по порядку.

1. **Интернет на роутере.** `ping -c 3 8.8.8.8` — ответы должны прийти.
2. **DNS на роутере.** `nslookup github.com` — должен прийти адрес.
3. **Время на роутере.** `date` — дата и время должны быть верными. С
   неверным временем роутер не проверит сертификат GitHub, и загрузка
   прервётся. На Keenetic включите синхронизацию времени в «Общих
   настройках».
4. **Пакеты Entware.** Если `opkg update` пишет ошибку загрузки, повторите
   через несколько минут. Сервер Entware иногда недоступен.
5. **Чужой прокси или VPN на роутере** может мешать загрузке. Временно
   выключите его.

### Установка без доступа к GitHub с роутера

Если GitHub с роутера не открывается совсем, а VPS проекта не отвечает,
поставьте D2K из архива, скачанного на компьютер.

1. На компьютере откройте https://github.com/necronicle/d2k/releases/latest
2. Скачайте архив своей архитектуры:

   | `uname -m` на роутере | Архив |
   | --- | --- |
   | `aarch64` | `d2k-arm64.tar.gz` |
   | `armv7l` | `d2k-arm.tar.gz` |
   | `mips` (Keenetic с MIPS — почти всегда этот) | `d2k-mipsel.tar.gz` |
   | `mips` (big-endian) | `d2k-mips.tar.gz` |
   | `mips64` | `d2k-mips64el.tar.gz` |
   | `x86_64` | `d2k-amd64.tar.gz` |
   | `i686` | `d2k-x86.tar.gz` |
   | `riscv64` | `d2k-riscv64.tar.gz` |
   | `ppc64` | `d2k-ppc64.tar.gz` |

   На MIPS порядок байт покажет `opkg print-architecture` (Keenetic) или
   `grep DISTRIB_ARCH /etc/openwrt_release` (OpenWrt): `mipsel` — первый
   вариант, `mips` — второй.
3. Скопируйте архив на роутер (на Keenetic порт 222):

   ```sh
   scp -P 222 d2k-arm64.tar.gz root@192.168.1.1:/tmp/
   ```

   В OpenWrt без `-P 222`. Если `scp` пишет ошибку про sftp, добавьте ключ `-O`.
4. На роутере распакуйте и запустите установщик из архива:

   ```sh
   mkdir -p /tmp/d2k-r && tar -xzf /tmp/d2k-*.tar.gz -C /tmp/d2k-r && D2K_LOCAL=/tmp/d2k-r sh /tmp/d2k-r/scripts/install.sh; rm -rf /tmp/d2k-r /tmp/d2k-*.tar.gz
   ```

Так подпись выпуска не проверяется. Берите архив только со страницы выпусков
проекта. Ночное обновление потом ставит подписанные выпуски как обычно.

## Как устроена установка

Установщик:

1. определяет архитектуру роутера;
2. берёт последний выпуск — перечень с подписью и архив своей архитектуры;
3. проверяет подпись перечня и контрольную сумму архива. Не сошлось —
   ничего не меняет;
4. проверяет пакеты, модули ядра и свободное место. Чего-то нет — пишет, чего
   именно, и ничего не меняет;
5. ставит D2K и запускает службу;
6. печатает адрес панели.

Ручная установка и ночное обновление ставят один и тот же подписанный
выпуск.

### Загрузки через VPS

Каждая загрузка — пакеты, установщик, выпуск, ночное обновление — сначала
идёт через VPS проекта (`85.192.60.175:9444`), а если он не отвечает —
напрямую.

- На VPS работает отдельный сервис D2K: relay-gate.
  Он пропускает загрузки только с GitHub, Entware и сервера пакетов
  OpenWrt.
- Соединение с GitHub шифруется на всём пути до GitHub, и роутер проверяет
  сертификат GitHub. VPS не может подменить установщик или выпуск. Выпуск
  дополнительно проверяется подписью.
- Пакеты OpenWrt идут штатными зеркалами по HTTP. `apk` и `opkg` проверяют
  подписи пакетов сами. Entware и без VPS ходит по HTTP.
- D2K не обрабатывает трафик к этому сервису: это канал самого D2K.

Выключить загрузки через VPS: `D2K_GATE=` перед командой установки или
строка `D2K_GATE=` в `/opt/d2k/config`.

Код установщика: [scripts/install.sh](scripts/install.sh).

## Windows: если сайты висят

Если на телефоне и Mac сайты открываются, а на компьютере с Windows долго
грузятся и обрываются, включите в Windows метки времени TCP. Откройте
командную строку от имени администратора:

```
netsh interface tcp set global timestamps=enabled
```

Вернуть как было:

```
netsh interface tcp set global timestamps=disabled
```

Часть обходов портит метку времени в поддельном пакете, чтобы сервер его
отбросил. В Windows метки по умолчанию выключены, и сервер принимает
подделку. От блокировки по адресу это не помогает.

## Проверка после установки

1. Выполните команду:

   ```sh
   /opt/etc/init.d/S99d2k status
   ```

2. Проверьте строки «датапат: работает» и «контроллер: работает».
3. Откройте панель (см. раздел [Панель](#панель)).

D2K запускается в рабочем режиме (`MODE=apply`).

Первый обход для нового сайта появляется не сразу. D2K сначала измеряет
соединение и только потом ставит обход.

D2K не трогает трафик, который работает. Медленный сайт — это ещё не
блокировка.

**Если сеть работает плохо после установки,** выполните:

```sh
/opt/etc/init.d/S99d2k stop
```

Эта команда останавливает D2K и снимает его правила.

Адрес панели: `http://<адрес-роутера>:8090/`.

Обычно это **http://192.168.1.1:8090/**. Точный адрес печатает установщик.

- найденные обходы;

**ВНИМАНИЕ:** У панели нет пароля. Не открывайте порт 8090 в интернет.

## Обновление

D2K обновляет себя сам.

1. Роутер проверяет новый выпуск ночью, между 03:00 и 05:00.
2. Роутер проверяет подпись выпуска. Если подпись неверна, роутер ничего не
   ставит. Выпуск роутер скачивает сначала через VPS проекта, потом напрямую.
3. Роутер сохраняет текущую версию.
4. Роутер ставит выпуск.
5. Через минуту роутер проверяет, что движок, контроллер и панель работают.
6. Если проверка не прошла, роутер возвращает прежнюю версию.

Кнопка «Установить сейчас» в разделе «Обновления» ставит выпуск сразу.

Тумблер в панели выключает ночную установку.

Обновление сохраняет настройки и подобранное.

Журнал обновлений: `/opt/d2k/log/update.log`.

## Управление

### Команды

| Команда | Что делает |
| --- | --- |
| `/opt/etc/init.d/S99d2k status` | показывает состояние |
| `/opt/etc/init.d/S99d2k stop` | останавливает D2K и снимает правила |
| `/opt/etc/init.d/S99d2k start` | запускает D2K |
| `/opt/etc/init.d/S99d2k restart` | перезапускает D2K |
| `/opt/etc/init.d/S99d2k clear-found` | стирает подобранное |

Настройки: `/opt/d2k/config`.

Журналы: `/opt/d2k/log/`.

### Только для политики Keenetic

D2K может работать только для устройств одной политики доступа Keenetic.
Остальные устройства и сам роутер идут как без D2K.

1. В веб-интерфейсе Keenetic создайте политику доступа в интернет.
   Оставьте в ней подключение к провайдеру — то же, что у остальной сети.
2. Добавьте в политику нужные устройства.
3. Впишите имя политики в `/opt/d2k/config` — так, как оно видно в
   веб-интерфейсе:

   ```sh
   KEENETIC_POLICY="Имя политики"
   ```

4. Перезапустите D2K: `/opt/etc/init.d/S99d2k restart`.

Команда `/opt/etc/init.d/S99d2k status` покажет политику и её метку. Если
политики с таким именем нет, D2K не обрабатывает ни одного устройства и
пишет об этом. Удалите строку из настроек — D2K снова работает для всей
сети.

Ограничения:

- Если политика ведёт трафик через VPN, а не через провайдера, D2K этот
  трафик не меняет: его посылки уходят через провайдера.
- Telegram через туннель D2K и DNS-записи для Instagram и WhatsApp работают
  для всей сети, как прежде.

### Стереть подобранное

**ВНИМАНИЕ:** Подобранное нельзя восстановить. После очистки D2K подбирает
каждый обход заново.

1. Откройте панель.
2. Нажмите «Очистить подобранное».
3. Прочитайте предупреждение.
4. Нажмите «Очистить».

Та же команда для SSH: `/opt/etc/init.d/S99d2k clear-found`.

Подобранное хранится в `/opt/d2k/state/`:

| Файл | Содержание |
| --- | --- |
| `catalog.json` | коробки и обходы TLS, QUIC и голоса |
| `http-plans.txt` | обходы открытого HTTP |
| `https-cache.txt` | проверки HTTPS для имён с подменой ответа |

Во время очистки движок останавливается. Потом он запускается снова.

## Удаление

**ВНИМАНИЕ:** Удаление стирает подобранное. Восстановить его нельзя.

### Keenetic и OpenWrt

```sh
(f=$(mktemp); u=https://raw.githubusercontent.com/necronicle/d2k/main/scripts/uninstall.sh; { curl -fsSL --proxy http://85.192.60.175:9444 --connect-timeout 8 --max-time 120 "$u" -o "$f" || curl -fsSL --connect-timeout 10 --max-time 120 "$u" -o "$f"; } && sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

### Что удаляет команда

- службы и панель D2K;
- правила D2K;
- DNS-записи D2K для Instagram и WhatsApp;
- настройки и подобранное;
- ключ Telegram.

Чужие правила и DNS-записи команда не удаляет.

На OpenWrt команда не удаляет пакеты. Другие программы могут их использовать.

### Сохранить настройки и подобранное

Добавьте `D2K_KEEP_STATE=1` перед `sh "$f"` в команде удаления.

Код удаления: [scripts/uninstall.sh](scripts/uninstall.sh).

## Instagram и WhatsApp

D2K сам ставит DNS-записи для Instagram и WhatsApp Web.

1. Роутер получает адреса от резолвера D2K на VPS.
2. Роутер проверяет, что адрес принадлежит Meta.
3. Роутер проверяет доступность адреса и его сертификат.
4. Роутер сохраняет 1–2 адреса на каждое имя.

Роутер обновляет записи каждый день, между 01:00 и 04:59. Каждая установка
выбирает свою минуту.

Если обновление не прошло, роутер повторяет его. Прежние записи остаются.

Каждый день роутер проверяет свои записи. Недоступную запись роутер снимает.

| Команда | Что делает |
| --- | --- |
| `/opt/d2k/d2k-instagram-dns.sh refresh` | обновляет записи сейчас |
| `cat /opt/d2k/state/instagram-ip-hosts.tsv` | показывает записи D2K |
| `tail -n 30 /opt/d2k/log/instagram-dns.log` | показывает журнал |

**ВНИМАНИЕ:** Не выключайте проверку сертификатов.

## Telegram

D2K включает Telegram-туннель сам.

Роутер создаёт свой ключ. Ключ не покидает роутер. Общий пароль не нужен.

Туннель ведёт только трафик Telegram. Остальной трафик идёт как обычно.

Если вы выключили туннель, обновление его не включает.

## Архитектуры

| Архитектура | Требования |
| --- | --- |
| ARM64 | AArch64 |
| ARM32 | ARMv7 и новее, little-endian, EABI, VFPv3 |
| MIPS / MIPSEL | MIPS32, big-endian или little-endian, soft-float |
| MIPS64EL | MIPS64, little-endian, N64 ABI, **нужен FPU** |
| x86 / x86-64 | i686 / x86-64 |
| PPC64 | 64-битный PowerPC, big-endian |
| RISC-V64 | RV64GC |

Каждый комплект собран статически. Библиотеки OpenSSL ставить не нужно.

D2K не работает на этих процессорах:

- Lexra;
- ARMv5 и ARMv6;
- 32-битный PowerPC;
- MIPS64EL без FPU.

Если архитектура неизвестна, установщик останавливается до любых изменений.
