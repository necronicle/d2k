# d2k — Dynamic2Keenetic

Обход блокировок без поставляемых списков доменов: система наблюдает
соединения, при сбое измеряет поведение блокирующей коробки, узнаёт её среди
уже изученных и пробует готовую стратегию — а полный подбор запускает только
там, где знания не хватило.

**Рабочей сборки нет.** Сейчас идёт этап A: основание продукта. Датапата,
обхода и установки пока не существует, и программа говорит об этом прямо —
`d2k status` перечисляет, какие звенья обработки написаны, а какие нет, а
панель показывает то же самое и отдельно объясняет, каких показаний у неё нет
и почему.

Полное описание архитектуры, принципов и того, что уже проверено замером, — в
[D2K_HANDOFF.md](D2K_HANDOFF.md). Это точка входа для всякого, кто берётся за
продолжение.

## Чем это не является

Не форк zapret и не обёртка над nfqws. Ни nfqws, ни nfqws2, ни Lua-библиотеки
Zapret не являются компонентами d2k: набор их примитивов не обязан покрывать
то, чем коробки уже обладают, а алфавит воздействий выводится из того, что
позволяет провод.

Опыт z2k используется как источник требований и как лабораторный эталон для
сравнения. Заимствованный код перечисляется явно; донор под лицензией MIT.

## Что уже измерено

Этап 0 закрыт, отчёты в [`docs/field/`](docs/field/):

- **горизонт видимости на Keenetic — регулятор, а не предел.** Правило `-j PPE`
  с широким `connskip` даёт стопроцентную видимость направления, сверенную с
  `conntrack` пакет в пакет. Регулятор односторонний: нужны два правила, по
  `--dports` и по `--sports`;
- **полная видимость доступна по цене.** Один клиент в обе стороны — 15 %
  ядра при 33 МБ/с; восемь параллельных потоков на 372 Мбит/с — около 10 %;
- **язык датапата выбран замером.** C и Rust неразличимы по процессору
  (15,0 % против 14,9 %), Go на голых сисколлах дороже в полтора раза по CPU и
  в шесть раз по памяти. Решил не замер, а тулчейн: MIPS обязателен, а у
  `rustup` нет ни одной MIPS-цели. Датапат — C, всё остальное — Go;
- **входящий RST цензора виден** на старте потока без всяких ухищрений, а
  пакет разрыва офлоаднутого потока возвращается в софт;
- **QUIC виден в обе стороны** тем же рычагом.

## Сборка

```sh
sh scripts/build.sh          # девять арок в builds/
go test -race ./...
```

Тулчейн Go закреплён на 1.25.12: иначе вердикт CI начинает зависеть от даты
прогона. `GOMIPS=softfloat` обязателен — на MIPS-роутерах нет сопроцессора.

## Использование

```sh
d2k version          # что за сборка запущена: версия, коммит, правки в дереве
d2k config           # показать конфигурацию; -write создать файл с умолчаниями
d2k status           # что программа делает прямо сейчас
d2k serve            # запустить службу и локальную панель
```

Панель поднимается на `127.0.0.1:8090` и открывается без интернета: внешних
шрифтов, CDN и подгружаемых библиотек в ней нет, всё вшито в бинарник, а
политика содержимого это проверяет. Панель только читает; изменяющих запросов
у неё нет, поэтому нет и аутентификации — первый такой запрос добавлять без
неё нельзя.

Её главное содержание сейчас — отсутствие. Обычная панель состояния успокаивает
зелёными точками; эта показывает цепочку обработки, где построенные звенья
залиты чернилами, а ненаписанные остаются дырками, сквозь которые видна
миллиметровка. Красного нет намеренно: ничего не сломано, просто не написано.

Путь к конфигурации — переменная `D2K_CONFIG`, иначе `/opt/d2k/config`.
