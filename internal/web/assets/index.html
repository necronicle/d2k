    Скачать отчёт
    Что сохраняется

    Последние 120 минутных снимков и 64 завершения поиска, только в оперативной памяти. Для разбора роста RAM также сохраняются первый и последний подробные снимки памяти процессов. Включите сбор, воспроизведите проблему и скачайте отчёт для issue — дополнительные команды на роутере не нужны. Отчёт содержит домены и IP-адреса; автоматически никуда не отправляется. Сбор по умолчанию выключен и отключается после перезагрузки. Перед выключением скачайте отчёт — история будет удалена.
