# QUIC: восстановление входа в оригинальный поиск

Продолжение после `ca5e6fb`, ветка `classify-core`. Цель — MVP по D2K_SPEC,
не новый алгоритм. Роутер в этой итерации не изменялся.

## Исправлено: восемь кадров вместо всех байтов

Полевой отчёт `2026-09-19-quic-field.md` зафиксировал много CRYPTO-кадров
в обратном порядке и две Initial-датаграммы клиента. `core/quic.c` сохранял
только первые восемь кадров, остальные молча отбрасывал. Даже полностью
доступный ClientHello внутри одной датаграммы мог не дать SNI.

Регрессия берёт ClientHello из RFC-вектора, разбивает на однобайтовые кадры
и шифрует существующим кодировщиком. Две версии (v1/v2) × два порядка кадров.
До исправления — 8 ожидаемых падений SNI/полного ClientHello. После — 0.
Повреждённый AEAD-тег по-прежнему отвергается. Проверка кодировщика остаётся
в независимых RFC-векторах `test_quicwire`, новый тест проверяет сборку кадров.

Теперь каждый кадр кладёт байты по смещению, а битовая карта помнит наличие.
Ограничения — прежние 1500 байт входа/собираемого сообщения, без выделений
и без массива по числу кадров. Выдаётся только непрерывный префикс от нуля.
Пропуски не заполняются; неизвестный хвост останавливает разбор как раньше.

Проверено: `test_quic`, `test_quichello`, `test_quicprobe`, `test_quic_arms`,
полный `make -C datapath check` — код 0. `test_quic` из исходников под
ASan/UBSan — код 0; этот же тест компилируется/линкуется для ARM64 musl и
MIPS glibc. Это не полевой прогон и не полная приёмка QUIC.

## Следующие разрывы (ещё открыты)

1. Между UDP-датаграммами состояния сборки пока нет. Извлечённое имя не
   разрешает выдать последнюю половину приветствия за полный снимок, а
   склейка датаграмм меняет измеряемую форму. Нужны ограниченная сборка,
   принадлежность соединению и явное сохранение границы наблюдённого входа.
2. В `core/sched.c:fill_hellos` утверждается, что QUIC без снимка мерить нечем.
   Это расходится с донором: `internal/quicprobe/probe.go:Run/buildInitial`
   создаёт собственный корректный ClientHello/Initial с новыми CID и ключами.
   Не путать запрещённую подстановку TLS-записи в UDP с разрешённым исходным
   QUIC-зондом. В C уже есть `d2k_qc_first_initial`; проверить его соответствие
   донору и подключение без ложного признака «измерено байтами клиента».
3. Протокольное подтверждение, адресный поиск, voice и полный цикл коробок
   остаются открытыми — см. актуальное начало MVP_CHECKLIST.
